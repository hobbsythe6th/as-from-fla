# as-from-fla
as-from-fla is a utility to get all your ActionScript code out of your old .FLAs.

We use only zip.js and Preact for the whole app.

You can use it at (https://hobbsythe6th.github.io/as-from-fla)[https://hobbsythe6th.github.io/as-from-fla]

All bugs can be reported here. This is NOT unmaintained, there just aren't any bugs to patch, and I'm too lazy to make it handle binary .FLAs.
